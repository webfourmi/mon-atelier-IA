# Suivi de la V2.0

## Réalisé et vérifié automatiquement

Les dix postes, le pilotage, les tâches, le dossier commun, les médias, les décisions, les transmissions et le comparateur sont intégrés. La migration des sauvegardes V1 et les exports avec fichiers originaux ont été testés. Les lectures GitHub publiques ont été essayées sur un dépôt réel ; les envois et conflits sont couverts par des simulations.

Résultat : 25 tests automatisés réussis. Le détail et les limites sont dans `VERIFICATIONS.md`.

## Prochain passage au poste Tests

Ouvrir `index.html` sur le PC, importer la sauvegarde V1 et contrôler le rendu, les menus, un fichier joint et une exportation. Vérifier le dossier local dans le navigateur choisi si cette option est utilisée.

## Prochain passage au poste Livraison

Dans l’application, associer le dépôt souhaité. Pour les opérations qui en ont besoin, connecter un jeton GitHub limité à ce dépôt. Préparer un aperçu avant le premier envoi de dossier.

Le code livré et les données personnelles du navigateur sont distincts. Les mises à jour du code ne transfèrent pas automatiquement les données entre les ordinateurs ou les services d’IA.
