MON ATELIER IA — V2.0 — 17 NOVEMBRE 2026

1. Décompresser les fichiers du dépôt.
2. Garder index.html, styles.css, core.js, github.js et app.js ensemble.
3. Ouvrir index.html dans Chrome, Edge ou Firefox.

AVANT LA MISE À JOUR
Dans la V1 : Sauvegarde > Exporter la sauvegarde JSON.
Garder le JSON et l’ancienne application pendant la mise à jour.
Dans la V2, si tes données ne sont pas déjà retrouvées :
Sauvegardes > Importer une sauvegarde > choisir le JSON de la V1.

LES NOUVEAUTÉS
- 10 postes de travail, avec leurs missions et consignes.
- Pilotage du projet et tâches avec intervenant, résultat et vérifications.
- Dossier commun : objectifs, règles, documents et fichiers originaux.
- Export du dossier en ZIP et choix d’un dossier local si le navigateur le permet.
- Transmissions ChatGPT / Claude avec contexte court, standard ou complet.
- Journal des propositions et décisions validées.
- Comparateur enrichi, sauvegardes complètes et copies automatiques.
- GitHub : dépôts, fichiers, issues et partage du dossier commun.

POUR UTILISER GITHUB
Ouvrir l’onglet GitHub du projet, associer son dépôt et vérifier l’accès.
Les dépôts publics sont lisibles sans jeton.
Pour les dépôts privés ou l’envoi du dossier, connecter un jeton personnel
à accès limité. Le jeton reste uniquement dans la session ouverte.

POUR RETROUVER LE DOSSIER DE MON ATELIER IA DANS L’APPLICATION
Sauvegardes > Ajouter un projet exporté > sélectionner
dossier-commun/mon-atelier-ia.projet.json.

Les échanges avec les IA restent manuels. Aucune API IA payante.
Le guide détaillé est dans README.md, les contrôles dans VERIFICATIONS.md.
Les données saisies dans ton navigateur ne sont pas contenues dans le dépôt.
